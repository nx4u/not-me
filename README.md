# مو أنا

نموذج ويب عربي للهاكثون يساعد المستخدم على فهم إشارات الاحتيال المالي وتجربة الإبلاغ.

## التشغيل
افتح `index.html` في متصفح حديث، أو شغّل خادم ملفات محليًا عبر `python3 -m http.server 8000` من مجلد المشروع.

## الرفع إلى GitHub
استخرج الملفات وارفعها إلى جذر المستودع. ملف `index.html` هو نقطة التشغيل، وملفات JavaScript الثلاثة تبقى بجانبه.

## ما يتضمنه النموذج
فحص الرسائل والإشعارات، تحليل تسلسل المحادثة، دليل توعية، تدريب تفاعلي، وبلاغات تجريبية مع لوحة متابعة ونتائج اختبار CSV.

الاتصال والإيقاف والإبلاغ البنكي محاكاة. صُممت التجربة للبيانات التدريبية.
